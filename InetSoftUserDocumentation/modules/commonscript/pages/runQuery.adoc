= runQuery(name [,parameters])
:navtitle: runQuery()
%experimental%
include::ROOT:partial$buttonSnippets.adoc[]

[WARNING,caption=See Also]
xref:dashboardscript:RunQueryFromScript.adoc[] for examples of executing Data Worksheet queries in a Dashboard.

Returns a query result set as a two-dimensional array.

== Parameters
name::			string containing the data block name
parameters::			 two-dimensional string array,			each row containing a name-value pair 			that corresponds to a query parameter (optional)

== Example
[source,javascript]
var rs = runQuery('ws:global:Sample Queries/All Sales',[['category','Business'],['price',100]]);

NOTE: The example ‘All Sales’ Data Worksheet (in menu:Data Worksheet[Sample Queries]) does not define these parameters, so this example only illustrates the syntax. To pass parameters to a Data Worksheet, the Data Worksheet must define variables with matching names. See xref:dataworksheet:CreateNewVariable.adoc[].
