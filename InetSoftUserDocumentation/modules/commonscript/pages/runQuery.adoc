Returns a query result set as a two-dimensional array.

== Parameters
name::			string containing the data block name
parameters::			 two-dimensional string array,			each row containing a name-value pair 			that corresponds to a query parameter (optional)

== Example
[source,javascript]
var rs = runQuery('ws:global:Sample Queries/Sales by Date Range',[['StartDate', new Date(2025,0,1)],['EndDate', new Date(2025,11,31)]]);

NOTE: The example ‘Sales by Date Range’ Data Worksheet (in menu:Data Worksheet[Sample Queries]) defines the `StartDate` and `EndDate` variables used here. To pass parameters to a Data Worksheet, the Data Worksheet must define variables with matching names. See xref:dataworksheet:CreateNewVariable.adoc[].
