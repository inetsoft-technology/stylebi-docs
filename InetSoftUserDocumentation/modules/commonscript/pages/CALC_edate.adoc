= CALC.edate(date, months)
:navtitle: CALC.edate()

Summary: Returns the date that is the specified number of months after (positive) or before (negative) a date, for use in expression columns, calculated fields, and Dashboard scripts. The result has the same day of the month as the original date, or the last day of the target month when that day does not exist (for example, one month after January 31 is February 28 or 29). This is also true when the result is in another year. The result is the same as dateAdd("m", months, date) and as the Excel EDATE function. See DateGlobalDateAdd.adoc for another function to compute future and past dates.
endif::ai[]

[WARNING, caption=see also]
xref:DateGlobalDateAdd.adoc[] for another function to compute future and past dates.


Returns a date that is the specified number of months before or after the date. {CALCExcelFunctionPage} A negative value for `months` represents a date prior to the specified date.

The result has the same day of the month as the specified date. If that day does not exist in the resulting month, the result is the last day of that month. For example, one month after January 31 is the last day of February. This is true when the result falls in a different year as well. The result is the same as that of xref:DateGlobalDateAdd.adoc[] with the `"m"` interval.


== Parameters
date::			Date object: date from which to begin counting
months::			Positive integer: Number of months to count forward  +
Negative integer: Number of months to count backward









== Example
[source,javascript]
----
// Add one month to Jan 14, 2000:
CALC.edate(new Date(2000,0,14), 1); // returns Feb 14, 2000

// The day does not exist in the resulting month,
// so the last day of the month is returned:
CALC.edate(new Date(2001,0,31), 1); // returns Feb 28, 2001
CALC.edate(new Date(2000,11,31), 2); // returns Feb 28, 2001

// Subtract one month from Jan 15, 2001:
CALC.edate(new Date(2001,0,15), -1); // returns Dec 15, 2000
----
