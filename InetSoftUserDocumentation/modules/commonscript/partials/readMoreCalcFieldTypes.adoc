[TIP,caption=tip: access your data in script]
=====

.How to access data in Data Worksheet Expression Columns...
[%collapsible]
====
To create an expression column in a Data Worksheet, press the {buttonCreateExpression}. (See xref:dataworksheet:CreateNewDataField.adoc[] for more details.)

image:dataworksheet:agileTransform3.png[alt="formula editor open after pressing create expression button"]

Insert fields (and parameters) into the script by clicking the items in the tree.

.Example syntax:
[source,javascript]
CALC.quarter(field['Order Date'])

image:dataworksheet:Expression1.png[alt="expression column formula entered in the formula editor script area"]


To reference the data contained in other cells of the data block, see the topics below:

include::partial$referenceCellsWorksheet.adoc[]
====

.How to access data in Dashboard Calculated Fields...
[%collapsible]
====
To create a *calculated field in a dashboard*, right-click on the data block, data model, or query to which you want to add the calculated field, and select ‘New Calculated Field’. (See xref:dataworksheet:CreateNewDataField.adoc[] for more details.)

image:dashboard:NewCalculatedField1.png[alt="new calculated field dialog after right-clicking a data block"]

Insert fields (and parameters and component properties) into the script by clicking the items in the tree.

.Example syntax:
[source,javascript]
CALC.quarter(field['Order Date'])

image:dashboard:CalcField1.png[alt="calculated field formula entered in the formula editor"]
====

.How to access data in Dashboard Property Expressions...
[%collapsible]
====

To set a Dashboard property value using an expression, press the {buttonValueType} and select the ‘Expression’ option to open the Formula Editor. (See xref:dashboard:DynamicallySetProperties.adoc[] for more details.)

Example: Gauge Properties::
image:dashboard:Expression Option.png[alt="expression option selected in gauge properties value type menu"]

Example: Chart Editor::
image:dashboard:ChartPropertyExpression.png[alt="expression option selected in chart editor property field"]

To insert a reference a component’s data, use the *value*, *selectedObjects*, *data*, or *table* property of the component.

.Example syntax:
[source,javascript]
CALC.quarter(Calendar1.selectedObjects[0])
CALC.quarter(TableView1.table['Order Date'][1])

See xref:dashboardscript:DashboardObjectReference.adoc[] for information about accessing dashboard settings and data in script.

image:dashboard:expressionData.png[alt="expression referencing component data using selectedObjects property"]

====


.How to access data in Dashboard Scripts...
[%collapsible]
====
To *add script to a Dashboard component*, right-click the desired component, and select ‘Properties’ from the context menu to open the ‘Properties’ panel. {rightClickOptions} Select the *Script* tab to open the Script Editor, and select either *Script* or *onClick*. See xref:dashboardscript:AddScriptToDashboard.adoc#AddComponentScript[Add Component Script] for more information about these options.

image:dashboardscript:ScriptEditorText.png[alt="script editor open on component properties script tab"]

To *add global script to a Dashboard*, press {buttonOptions} in the toolbar to open the ‘Dashboard Options’ panel. Select the *Script* tab to open the Script Editor, and select either *onInit* or *onRefresh*. See xref:dashboardscript:AddScriptToDashboard.adoc#AddDashboardScript[Add Dashboard Script] for more information about these options.

image:dashboard:ViewsheetOptionsDialog.png[alt="dashboard options dialog with script tab selected"]

To insert a reference a component’s data, use the *value*, *selectedObjects*, *data*, or *table* property of the component.

.Example syntax:
[source,javascript]
CALC.quarter(Calendar1.selectedObjects[0])
CALC.quarter(TableView1.table['Order Date'][1])

image:dashboard:ScriptComponentData.png[alt="script accessing component data using table property syntax"]


See xref:dashboardscript:DashboardObjectReference.adoc[] for information about accessing dashboard settings and data in script.

ifdef::ai[]
This function can be used in four places, and each exposes the data differently:

* *Data Worksheet Expression Column:* press the Create Expression button on a data block, and insert fields (and parameters) by clicking items in the tree. Reference the current row with `field['Column']`, for example `CALC.quarter(field['Order Date'])`. See Access Data in Expression for referencing other rows, other data blocks and lookups.
* *Dashboard Calculated Field:* right-click the data block, data model or query, select ‘New Calculated Field’, and insert fields (and parameters and component properties) by clicking items in the tree, for example `CALC.quarter(field['Order Date'])`.
* *Dashboard property expression:* press the value type button next to a property and select ‘Expression’ to open the Formula Editor. Reference a component’s data with its *value*, *selectedObjects*, *data* or *table* property, for example `CALC.quarter(Calendar1.selectedObjects[0])` or `CALC.quarter(TableView1.table['Order Date'][1])`.
* *Dashboard script:* in a component’s Properties panel, use the Script tab; for global script, use the Script tab of Dashboard Options (onInit or onRefresh). Reference component data the same way as in a property expression.
endif::ai[]
