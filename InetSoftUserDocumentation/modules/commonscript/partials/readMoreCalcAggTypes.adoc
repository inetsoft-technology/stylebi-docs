[TIP,caption=tip: access your data in script]
=====

.How to access data in Data Worksheet Expression Columns...
[%collapsible]
====
To create an expression column in a Data Worksheet, press the {buttonCreateExpression}. (See xref:dataworksheet:CreateNewDataField.adoc[] for more details.)

image:dataworksheet:agileTransform3.png[alt="formula editor open after pressing create expression button"]

Type the desired expression into the script area. To add a field into the expression, click on the field name in the ‘Fields’ listing. To reference a column of this or another data block, use the data block name.


.Example syntax:
[source,javascript]
----
// Average of ‘Total’ column in Data Worksheet ‘Sales’ data block:
CALC.average(Sales['Total']);
----



To reference the data contained in other cells of the data block, see the topics below:

include::partial$referenceCellsWorksheet.adoc[]
====


.How to access data in Dashboard Property Expressions...
[%collapsible]
====

To set a Dashboard property value using an expression, press the {buttonValueType} and select the ‘Expression’ option to open the Formula Editor. (See xref:dashboard:DynamicallySetProperties.adoc[] for more details.)

Example: Gauge Properties::
image:dashboard:Expression Option.png[alt="expression option selected in gauge properties value type menu"]

Example: Chart Editor::
image:dashboard:ChartPropertyExpression.png[alt="expression option selected in chart editor property field"]

To insert a reference a component’s data, use the *value*, *selectedObjects*, *data*, or *table* property of the component. You can also reference data in the underlying Data Worksheet.

.Example syntax:
[source,javascript]
----
// Average of ‘Total’ column in Data Worksheet ‘Sales’ data block:
CALC.average(Sales[‘Total’]);

// Average of ‘Total’ column in Dashboard ‘TableView1’ table:
CALC.average(TableView1.table[‘Total’])
----
image:dashboard:TableDataAccess.png[alt="script accessing table data using component table property"]


See xref:dashboardscript:DashboardObjectReference.adoc[] for information about accessing dashboard properties  in script.  See xref:dashboardscript:AccessComponentData.adoc[] and xref:dashboardscript:AccessDataSourceData.adoc[] for more information about accessing Dashboard and Data Worksheet data.

====


.How to access data in Dashboard Scripts...
[%collapsible]
====
To *add script to a Dashboard component*, right-click the desired component, and select ‘Properties’ from the context menu to open the ‘Properties’ panel. {rightClickOptions} Select the *Script* tab to open the Script Editor, and select either *Script* or *onClick*. See xref:dashboardscript:AddScriptToDashboard.adoc#AddComponentScript[Add Component Script] for more information about these options.

image:dashboardscript:ScriptEditorText.png[alt="script editor open on component properties script tab"]

To *add global script to a Dashboard*, press {buttonOptions} in the toolbar to open the ‘Dashboard Options’ panel. Select the *Script* tab to open the Script Editor, and select either *onInit* or *onRefresh*. See xref:dashboardscript:AddScriptToDashboard.adoc#AddDashboardScript[Add Dashboard Script] for more information about these options.

image:dashboard:ViewsheetOptionsDialog.png[alt="dashboard options dialog with script tab selected"]

To insert a reference a component’s data, use the *value*, *selectedObjects*, *data*, or *table* property of the component. You can also reference data in the underlying Data Worksheet.

.Example syntax:
[source,javascript]
----
 // Average of ‘Total’ column in Data Worksheet ‘Sales’ data block:
CALC.average(Sales[‘Total’]);

// Average of ‘Total’ column in Dashboard ‘TableView1’ table:
CALC.average(TableView1.table[‘Total’])
----
image:dashboard:TableDataAccess.png[alt="script accessing table data using component table property"]


See xref:dashboardscript:DashboardObjectReference.adoc[] for information about accessing dashboard properties  in script.  See xref:dashboardscript:AccessComponentData.adoc[] and xref:dashboardscript:AccessDataSourceData.adoc[] for more information about accessing Dashboard and Data Worksheet data.

ifdef::ai[]
This function takes a column (array) of values, and the column can be referenced in three places:

* *Data Worksheet Expression Column:* press the Create Expression button on a data block, type the expression, and click a field name in the ‘Fields’ listing to insert it. Reference a column of this or another data block by the data block name, for example `CALC.average(Sales['Total'])`. See Access Data in Expression for referencing other rows, other data blocks and lookups.
* *Dashboard property expression:* press the value type button next to a property and select ‘Expression’ to open the Formula Editor. Reference a component’s data with its *value*, *selectedObjects*, *data* or *table* property, for example `CALC.average(TableView1.table['Total'])`. You can also reference data in the underlying Data Worksheet, for example `CALC.average(Sales['Total'])`.
* *Dashboard script:* in a component’s Properties panel, use the Script tab; for global script, use the Script tab of Dashboard Options (onInit or onRefresh). Reference data the same way as in a property expression.
endif::ai[]
