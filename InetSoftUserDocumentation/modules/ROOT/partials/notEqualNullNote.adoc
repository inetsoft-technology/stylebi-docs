NOTE: *Null values:* An `[is not][equal to]` condition does not return rows where the value is null, the same as the other negated operators (for example, `[is not][one of]`) and as a condition sent to the database. Rows where the value is an empty string are still returned. To keep the rows with a null value, combine the condition with an `[or]` clause that uses `[is][null]`. Highlight conditions and chart color conditions are not affected.
