NOTE: *Null values:* An `[is not][equal to]` condition *does not return rows* where the value is *null*. This is the same behavior as the other negated operators (for example, `[is not][one of]`), and conditions sent to the database. Rows where the value is an empty string are still returned, unless the Dashboard uses a materialized view (see xref:administration:MaterializedView.adoc[]). To keep rows with a null value, combine the condition with an `[or]` clause that uses `[is][null]`. This does not apply to highlight conditions.
