TIP: *Case Sensitivity*: When a data block condition is pushed to the database, case sensitivity is *determined by the database*. To ensure a match on a case-sensitive database, use the {buttonBrowseData}  to insert the correct value. When a condition is evaluated in memory (as for embedded and imported tables, mirrors, and conditions added to unmergeable queries), case sensitivity follows the `string.compare.casesensitive` server property, which is *case-insensitive* by default.
