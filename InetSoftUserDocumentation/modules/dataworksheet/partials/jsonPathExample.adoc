.Example: JSON Path...
[%collapsible]
=====
Consider the data at https://jsonplaceholder.typicode.com/users.  The JSONPath string

 $.[*][?(@.id < 4)]

retrieves all fields (because none are specified) from all objects where the `id` field value is less than 4. The JSONPath string

 $.[*][?(@.id < 4)].email

retrieves just the `email` field from all objects where the `id` field value is less than 4.

Some web services wrap the array of results inside a named field of a top-level object, rather than returning a bare array. For example, `https://api.stripe.com/v1/charges` returns:

[source,json]
----
{
  "object": "list",
  "url": "/v1/charges",
  "has_more": false,
  "data": [
    { "id": "ch_1", "amount": 1099 },
    { "id": "ch_2", "amount": 500 }
  ]
}
----

To select and expand the `data` array, use the JSONPath string

 $.data[*]

Some web services return a response that is itself an array whose elements are different kinds of content, such as pagination metadata followed by the actual data. For example, `https://api.worldbank.org/v2/country/all/indicator/NY.GDP.PCAP.CD?format=json` returns:

[source,json]
----
[
  { "page": 1, "pages": 106, "per_page": 50, "total": 5300 },
  [
    { "country": { "value": "Aruba" }, "date": "2024", "value": 1234.5 },
    { "country": { "value": "Aruba" }, "date": "2023", "value": 1200.1 }
  ]
]
----

The first element (index `0`) is the metadata object, and the second element (index `1`) is the array of data records. To select and expand the data records, use the JSONPath string

 $.[1][*]

This selects index `1` of the top-level array (the data records) and expands its elements into rows.
