Summary: Chart Script API reference for `IntervalElement.setBridgeLine(Color, GLine)`. This is part of StyleBI's Chart Script (Chart API) scripting layer — a last-resort approach for chart customization/interactivity. See chartAPI:ChartScriptTutorial.adoc for guidance on when to use scripting vs. UI-driven alternatives (built-in toolbar tools, Ad Hoc Editor, Form-driven dynamic properties). There is no GUI equivalent. Bridge lines are drawn only on an element marked as a waterfall element. A chart created with the Waterfall style (xref:dashboard:WaterfallChart.adoc[]) is marked automatically, so on such a chart use xref:chartAPI:EGraphGetElement.adoc[] to get a handle to the element and call `setBridgeLine()` (Example 1). A Chart Component Script that builds a new `EGraph` from scratch must first call xref:chartAPI:IntervalElementSetWaterfall.adoc[] with `true` on the `IntervalElement` (Example 2). On a regular bar element (not marked as waterfall), `setBridgeLine()` has no effect.
endif::ai[]

Adds connector ("bridge") lines between adjacent bars for a xref:dashboard:WaterfallChart.adoc[] only, visually linking the end of each bar to the start of the next. The corresponding “getter” functions are `getBridgeLineColor()` and `getBridgeLineStyle()`.



[NOTE]
====
[square]
* If your Chart is built from scratch in script, as in xref:#Example2[] below, you must call xref:IntervalElementSetWaterfall.adoc[setWaterfall(true)] before using `setBridgeLine()`. This is not needed for a Chart created in the Chart Editor, as in xref:#Example1[].
* Bridge lines are not drawn on a chart with a reversed X-axis.
====
