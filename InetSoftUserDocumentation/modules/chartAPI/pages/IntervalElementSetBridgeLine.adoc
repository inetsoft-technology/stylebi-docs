This is part of StyleBI's Chart Script (Chart API) scripting layer — a last-resort approach for chart customization/interactivity. See chartAPI:ChartScriptTutorial.adoc for guidance on when to use scripting vs. UI-driven alternatives (built-in toolbar tools, Ad Hoc Editor, Form-driven dynamic properties). There is no GUI equivalent. Unlike most chartAPI properties, this one cannot be demonstrated on a chart built entirely from script — a bar element is only internally marked as a "waterfall" element (letting bridge lines render) when the graph is generated by the framework from the chart's own binding configuration set to the Waterfall style (however that style was set — Chart Editor or onRefresh script), not when a Chart Component Script builds a new `EGraph` from scratch. Use xref:chartAPI:EGraphGetElement.adoc[] to get a handle to an element from such a chart, as shown in the example below.
endif::ai[]

Adds connector ("bridge") lines between adjacent bars on a xref:dashboard:WaterfallChart.adoc[], visually linking the end of each bar to the start of the next. The corresponding “getter” functions are `getBridgeLineColor()` and `getBridgeLineStyle()`.

NOTE: Bridge lines are not drawn on a chart with a reversed X-axis.

== Parameters
Color:: The bridge line color, or `null` to use the default line color.
