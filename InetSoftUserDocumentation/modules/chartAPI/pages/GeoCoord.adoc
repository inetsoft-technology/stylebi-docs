The `GeoCoord` object is the coordinate system of a map chart. It maps longitude and latitude values onto the rectangular chart area using a Mercator projection. (See xref:dashboard:MapChart.adoc[] for information about creating a map chart.)

In the script of a map chart, use xref:EGraphGetCoordinate.adoc[] to obtain the `GeoCoord` object:

[source,javascript]
var coord = graph.getCoordinate();
