Sets the corner of a xref:dashboard:TreemapChart.adoc[] in which the largest rectangle is placed. By default, the largest rectangle is in the top-left corner, and the remaining rectangles are arranged by size from there. The corresponding “getter” function is `getOrientation()`.

The orientation mirrors the entire layout, so the nested rectangles of each hierarchy level move together with their parents. The `setOrientation` function  changes only the arrangement, not the data or the size of any rectangle.

[NOTE]
====
[square]
* The orientation applies only to xref:dashboard:TreemapChart.adoc[], and   has no effect on  xref:dashboard:SunburstChart.adoc[], xref:dashboard:IcicleChart.adoc[], or xref:dashboard:CirclePackingChart.adoc[].
* The orientation must be one of the four `TreemapElement.Orientation` constants. Passing `null` generates  an error.
====

== Parameter
orientation:: A `TreemapElement.Orientation` constant specifying the corner for the largest rectangle:
+
[source]
----
TreemapElement.Orientation.TOP_LEFT       (default)
TreemapElement.Orientation.TOP_RIGHT
TreemapElement.Orientation.BOTTOM_LEFT
TreemapElement.Orientation.BOTTOM_RIGHT
----
