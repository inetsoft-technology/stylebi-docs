Retrieves the element border color.  The corresponding “setter” function is xref:chartAPI:GraphElementSetBorderColor.adoc[].

== Returns
A {javaawtcolor} object

== Example

.Chart Component Script
[source,javascript]
----
var elem = graph.getElement(0); //<1>
var color = elem.getBorderColor(); //<2>
----
<1> Use xref:EGraphGetElement.adoc[] to obtain a handle to the xref:GraphElement.adoc[] object.
<2> Use `getBorderColor` to get the current border color.
