A Circular Network chart created in the Chart Editor draws a light gray dashed ring (`GShape.CIRCLE`, `GLine.MEDIUM_DASH`) automatically; call `addShapeBorder()` to change its color or line style, or pass `null` as the shape to remove the ring. Sets the characteristics of the "`ring`" that is drawn through the  nodes on a xref:dashboard:CircularNetworkChart.adoc[]. This allows you to remove  the default  gray dashed ring, or change its color or line style.


[NOTE]
====
[square]
* The ring is drawn only for the circular layout. On a xref:dashboard:TreeChart.adoc[] or xref:dashboard:NetworkChart.adoc[], `addShapeBorder()` has no effect.
* Use *only* `GShape.CIRCLE` for the shape. Other shapes do not follow the node positions.
====

== Parameters
GShape:: A xref:GShape.adoc[] constant specifying the shape of the ring (normally `GShape.CIRCLE`), or `null` to remove the ring.
Color:: A {javaawtcolor} object specifying the ring color, or `null` to use the default line color, a light gray.
GLine:: A xref:GLine.adoc[] constant specifying the line style, or `null` to use `GLine.THIN_LINE`. The default ring uses `GLine.MEDIUM_DASH`.
