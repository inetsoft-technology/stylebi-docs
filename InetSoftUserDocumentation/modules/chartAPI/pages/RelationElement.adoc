The `RelationElement` object contains the visual elements for a chart that displays relationships between nodes: a xref:dashboard:TreeChart.adoc[], xref:dashboard:NetworkChart.adoc[], or xref:dashboard:CircularNetworkChart.adoc[]. Each node is connected by a line to its related nodes, as defined by a '`Source`' field and a '`Target`' field.

To modify a Tree, Network, or Circular Network chart that was created in the Chart Editor, use xref:EGraphGetElement.adoc[] to obtain a handle to the chart's `RelationElement`:

[source,javascript]
var elem = graph.getElement(0);
