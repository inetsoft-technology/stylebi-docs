Specifies that the text color for labels on a xref:dashboard:BarChart.adoc[] (text that appears within the colored bars) should be automatically adjusted to enhance readability.






== Parameter
Boolean:: `true`: automatically adjust text color +
`false`: do not automatically adjust text color (default)
