Marks an `IntervalElement` as belonging to a waterfall chart, which enables waterfall-only behavior such as the connector lines set by xref:chartAPI:IntervalElementSetBridgeLine.adoc[]. A chart created with the Waterfall style (xref:dashboard:WaterfallChart.adoc[]) is marked automatically, so this is needed only when a Chart Component Script builds a new `EGraph` from scratch. On an element that is not marked, `setBridgeLine()` has no effect.

Specifies whether the `IntervalElement` belongs to a xref:dashboard:WaterfallChart.adoc[], which enables waterfall-only features such as bridge lines. See xref:IntervalElementSetBridgeLine.adoc[]. The corresponding “getter” function is `isWaterfall()`.

NOTE: You do not need to use `setWaterfall(true)` if the xref:dashboard:WaterfallChart.adoc[] was created in the Chart Editor. Use `setWaterfall(true)` only when you build the Chart from scratch using script, as shown in the example below.

== Parameter
Boolean:: `true`: element belongs to a waterfall chart +
`false`: element is a regular bar element (default)
