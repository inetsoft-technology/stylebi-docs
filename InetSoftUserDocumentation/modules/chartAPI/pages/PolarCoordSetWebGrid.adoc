Enables a polygon ("spider-web") grid instead of the default circular-ring grid for a  xref:dashboard:RadarChart.adoc[]. Each concentric grid ring becomes an N-sided polygon, where N is the number of dimensions on the chart (for example, a hexagon for six dimensions), and the outer axis boundary becomes the matching polygon shape instead of a circle. The corresponding “getter” function is `isWebGrid()`.


== Parameter
Boolean::			`true`: polygon ("`spider-web`") grid +
`false`: circular-ring grid (default)

[TIP]
=====
To change the property on a Chart that was *previously created* with the Chart Editor, use xref:chartAPI:EGraphGetCoordinate.adoc[] {circle1} to obtain a handle to the desired xref:chartAPI:Coordinate.adoc[] object. For example:

[source,javascript]
----
var coord = graph.getCoordinate(); //<1>
coord.setWebGrid(true);
----
