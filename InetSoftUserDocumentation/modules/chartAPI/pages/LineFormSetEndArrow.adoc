Specifies whether an arrow should be drawn at the end of the line (i.e., at the last point specified for the xref:LineForm.adoc[]).  The corresponding “getter” function is `isEndArrow()`.


== Parameter
Boolean:: `true`: draw arrow +
`false`: no arrow
