Specifies whether axis labels are centered between tick marks rather than aligned with tick marks. When the setting is `true`, each label is centered in the interval between its own tick mark and the next one. The last label is centered between the last tick mark and the end of the axis. The corresponding “getter” function is `isLabelBetween()`.



[NOTE]
====
[square]
* The setting takes effect only when the axis has one label for each tick mark, as on a date axis that labels every tick. Otherwise, the labels remain at the tick marks.
* A xref:dashboard:GanttChart.adoc[] created in the Chart Editor  labels the time axis  this way by default.
====

== Parameter
Boolean:: `true`: center each label between tick marks +
`false`: align each label with its tick mark (default)
