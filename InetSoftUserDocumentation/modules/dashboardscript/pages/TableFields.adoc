Specifies the fields of the data block to be displayed in the Table.

== Type
Array




== Example

. Create a new Dashboard based on the ‘ProductSales’ Data Worksheet.
include::ROOT:partial$CreateNewDashboardNote.adoc[]
+
include::ROOT:partial$ProductSalesWorksheet.adoc[]

. Add a Table component to the Dashboard. (The default name of this component is ‘TableView1’.)

. Add the following script to the Table component. (See xref:dashboardscript:AddScriptToDashboard.adoc#AddComponentScript[Add Component Script].)
+
[source,javascript]
----
TableView1.query = 'SalesByDate';
TableView1.fields = ['State','Company','Total'];
----
+
image::tableFields.png[alt="table showing State Company and Total columns bound from SalesByDate data block"]

[TIP]
====
Either syntax below can be used in  xref:AddScriptToDashboard.adoc#AddComponentScript[component script]:
[source,javascript]
fields                // unqualified
TableView1.fields     // qualified
