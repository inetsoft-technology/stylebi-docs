Specifies that the aggregated measure should be displayed as a bar. This is equivalent to selecting ‘Bar’ under the *Data* tab of the component ‘Properties’ dialog box.

image:dashboard:SelectionListShowBar.png[alt="selection component Data tab with Bar option enabled for measure display"]







== Type
Boolean::	`true`: show bar +
`false`: hide bar


== Example

. Create a new Dashboard based on the ‘ProductSales’ Data Worksheet.
include::ROOT:partial$CreateNewDashboardNote.adoc[]
+
include::ROOT:partial$ProductSalesWorksheet.adoc[]

. Add a Selection List component to the Dashboard. (The default name of this component is ‘SelectionList1’.)

. Add the following script to the Selection List component. (See xref:dashboardscript:AddScriptToDashboard.adoc#AddComponentScript[Add Component Script].)
+
[source,javascript]
----
SelectionList1.query = 'SalesByDate';
SelectionList1.fields = ['State'];
SelectionList1.measure = 'Total';
SelectionList1.formula = StyleConstant.MAX_FORMULA;
SelectionList1.showBar = true;
----

[TIP]
====
Either syntax below can be used in  xref:AddScriptToDashboard.adoc#AddComponentScript[component script]:
[source,javascript]
showBar                   // unqualified
SelectionList1.showBar    // qualified

{secondForm}
====
