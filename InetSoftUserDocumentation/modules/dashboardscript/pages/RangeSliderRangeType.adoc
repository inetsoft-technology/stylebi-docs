Specifies the display mode for the Range Slider. This is equivalent to selecting a data type in the ‘Options’ panel of the *Advanced* tab in the ‘Properties’ dialog box.

image:dashboard:rangeSliderRangeType.png[alt="range slider Advanced tab showing range type data type selection"]

== Type
xref:commonscript:StyleConstant.adoc[] object:: `StyleConstant.NUMBER` +
`StyleConstant.YEAR` +
`StyleConstant.MONTH` +
`StyleConstant.DAY`






== Example

. Create a new Dashboard based on the ‘Sales Explore’ Data Worksheet.
include::ROOT:partial$CreateNewDashboardNote.adoc[]
+
include::ROOT:partial$SalesExploreWorksheet.adoc[]

. Add a Range Slider component to the Dashboard. (The default name of this component is ‘RangeSlider1’.)

. Add the following script to the Range Slider component. (See xref:dashboardscript:AddScriptToDashboard.adoc#AddComponentScript[Add Component Script].)
+
.Single-value Range Slider
[source,javascript]
----
RangeSlider1.composite = false;
RangeSlider1.query = 'Sales';
RangeSlider1.fields = ['Date'];
RangeSlider1.rangeType = StyleConstant.MONTH;
----

[TIP]
====
Either syntax below can be used in  xref:AddScriptToDashboard.adoc#AddComponentScript[component script]:
[source,javascript]
rangeType                  // unqualified
RangeSlider1.rangeType     // qualified

{secondForm}
====
