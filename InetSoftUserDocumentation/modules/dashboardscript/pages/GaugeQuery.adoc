Specifies the data block to be used by the Gauge component. The available data blocks appear at the top of the *Toolbox* panel in Visual Composer.

image:dataworksheet:dataBlocks_6.png[alt="Toolbox panel showing available data blocks for gauge query binding"]







== Type
String



== Example

. Create a new Dashboard based on the ‘Sales Explore’ Data Worksheet.
include::ROOT:partial$CreateNewDashboardNote.adoc[]
+
include::ROOT:partial$SalesExploreWorksheet.adoc[]

. Add a Gauge component to the Dashboard. (The default name of this component is ‘Gauge1’.)

. Add the following script to the Gauge component. (See xref:dashboardscript:AddScriptToDashboard.adoc#AddComponentScript[Add Component Script].)
+
[source,javascript]
----
Gauge1.query = 'Sales';
Gauge1.fields = ['Total'];
Gauge1.formula = StyleConstant.AVERAGE_FORMULA;
----

[TIP]
====
Either syntax below can be used in  xref:AddScriptToDashboard.adoc#AddComponentScript[component script]:
[source,javascript]
query           // unqualified
Gauge1.query    // qualified

{secondForm}
====
